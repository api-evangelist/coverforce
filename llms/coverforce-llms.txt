# CoverForce

> CoverForce is a commercial insurance distribution infrastructure platform headquartered in New York. It provides a unified API and white-label software that enables insurance agencies, agency networks, wholesalers, carriers, insurtechs, and developers to digitally submit, quote, compare, bind, pay, and issue commercial insurance policies across 40+ carriers through a single integration. CoverForce is not an insurance agency or broker — it is an independent technology platform that strengthens (not disintermediates) independent agents. Founded in 2021 by Cyrus Karai (CEO), Behram Dinshaw (Chairman, former EVP at Travelers), and Kaivan Wadia (CTO, former Amazon engineer). Backed by Insight Partners, Nyca Partners, and QED Investors with $18M+ in funding. Named to the CB Insights Insurtech 50 in 2025. A product of the University of Pennsylvania Innovation Fund.

CoverForce offers three core product categories that can be used independently or together: (1) white-label software platforms for agents, networks, wholesalers, and carriers, (2) a standalone RESTful API for developers and insurtechs, and (3) AI-powered capabilities for document reading, carrier integration, and underwriting automation. The platform supports Workers' Compensation, General Liability, Business Owners Policy (BOP), Cyber, Commercial Auto, Inland Marine, Management Liability (D&O, EPLI, Fiduciary), Product Liability, and Miscellaneous Professional Liability (MPL) across all 50 US states.

## Platform Products

- [Agent Platform](https://www.coverforce.com/products/agent-platform): White-label agency platform for submitting, quoting, comparing, and binding commercial insurance policies across multiple carriers. Features include unified multi-carrier applications, AI-powered document ingestion, instant carrier quotes, one-click bind and pay, certificate of insurance generation, and integration with agency management systems like Nexsure, AMS360 and Applied Epic.
- [Network Platform](https://www.coverforce.com/products/network-platform): Unified quoting, performance tracking, and white-label digital storefronts for insurance agency networks. Enables network leadership to monitor placement activity across member agencies. Used by ISU Insurance Agency Network (240+ members, ~$8B in written P&C premiums).
- [Wholesaler Platform](https://www.coverforce.com/products/wholesaler-platform): Digital submission and distribution platform for wholesale insurance brokers. Manage broker codes, delegate access to retail agencies, and streamline distribution with white-label storefronts and reporting. Used by Amwins, Jencap, RT Specialty, Brooks Insurance (Venbrook Group), and First Connect.
- [Carrier Platform](https://www.coverforce.com/products/carrier-platform): Digital distribution platform for insurance carriers and MGAs. Provides API distribution, data insights, and multi-channel access to appointed distribution partners. Includes carrier API development consultancy for carriers without existing APIs.

## API

- [API Overview](https://www.coverforce.com/api): Unified commercial insurance API connecting to 40+ carriers and MGAs through a single integration. 40+ products integrated, 100K+ processed applications, 99.9% uptime. Key endpoints include /Applications (create and submit in unified JSON schema), /Quotes (retrieve multi-carrier quotes in consistent format), /Bind (request bindable terms directly via API), /Document AI (extract and populate application data from uploaded documents), /Renewals (start renewals with pre-filled data), /Appetite (query carrier appetite and eligibility dynamically), /Status (real-time application and quote status), /Analytics (usage metrics, bind ratios, performance reports), and /Documents (request policy documents for a given application and quote).
- [API Access Request](https://www.coverforce.com/api-access): Request access to CoverForce's API documentation and developer sandbox.
- [Developer Portal](https://coverforce.stoplight.io/): Full API reference documentation hosted on Stoplight, including endpoint specifications, authentication details, and code examples.
- [2026 Carrier API Index](https://www.coverforce.com/carriers/api-index): Comprehensive index of all carrier API integrations available through CoverForce, organized by carrier and policy type.

## AI Capabilities

- [AI Overview](https://www.coverforce.com/ai): CoverForce AI capabilities built in partnership with leading AI providers. Five core capabilities: (1) AI-Powered Document Reader — reads and extracts structured data from ACORD forms, quote proposals, policy docs, and custom intake forms with 95%+ accuracy, populating applications in seconds. (2) AI NAICS-to-Carrier Code Mapping — dynamically maps between NAICS codes and carrier-specific industry codes to improve classification accuracy. (3) Carrier API Integration Acceleration — uses AI to translate between carrier-specific APIs and the CoverForce unified API model, increasing integration speed. (4) Smart Underwriting Question Consolidation — identifies overlapping underwriting questions across carriers and merges them into unified smart questions for faster multi-carrier quoting. (5) Email-Based Submissions (upcoming) — agents email in submissions and AI extracts details, creates the application, and routes to the correct market.
